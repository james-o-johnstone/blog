I never thought I would call myself a Java developer. I started my career in the world of scientific computing with C++, Python and Matlab, slowly transitioning into a world where I use Java and Kotlin on a daily basis for employment, and I have really grown to love the ecosystem. The developer experience, libraries and performance are great and I can get into an enjoyable flow state when writing Kotlin. Don't get me wrong, for my own side projects I prefer Go because it's a much lighter and simpler language, filled with less cruft and is much easier to prototype with.
